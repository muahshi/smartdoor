# ai/knowledge

## Purpose
The knowledge base layer for SDOS — structured and unstructured reference
material that AI executives will draw on to understand the business:
policies, product context, historical decisions, glossaries, and summaries
derived from SmartDoor's own docs and data.

## Status
Empty. Phase 0 does not populate any knowledge content.

## What will eventually go here
- Curated/derived knowledge (e.g. a distilled summary of `BUSINESS_RULES.md`
  formatted for AI consumption)
- Domain glossaries (SmartDoor-specific terms, plan tiers, roles)
- Indexed or embedded reference material for retrieval

## What does NOT go here
- The source of truth itself — SmartDoor's actual database, `BUSINESS_RULES.md`,
  `SYSTEM_ARCHITECTURE.md`, etc. remain in the existing repository locations
  and are never duplicated or moved here. This folder holds AI-facing views
  derived from that source of truth, not replacements for it.
