# CEO Daily Routines

The CEO's planned daily operating cadence, once active in a future
phase. Deliberately narrower than any sibling executive's own daily
routine, because the CEO has no domain data of its own to check daily —
see `EXECUTIVE_MEETING_GUIDE.md`'s note on why there is no full daily
cross-domain review.

## What the CEO Checks Daily

1. **Any escalation that has crossed a domain boundary since
   yesterday**, per `EXECUTIVE_ESCALATION.md` — not each domain's full
   ticket/bug/campaign queue, only items already flagged by a sibling
   executive as touching more than one domain.
2. **Any P0/P1-equivalent item in a sibling executive's own escalation
   path** (e.g. `coo/ESCALATION_MATRIX.md`) that the founder may want
   framed with cross-domain context before acting on it.

## What the CEO Deliberately Does Not Check Daily

- Each domain's full queue (feature requests, support tickets, bug
  reports, campaign calendar, cash position) — that stays each
  sibling executive's own daily routine (`cto/`, `coo/`, `cfo/`, `cmo/`,
  `cpo/` each define this for their own domain). A daily full
  five-domain sweep would be overhead without proportionate value at
  SmartDoor's current single-founder scale.
- Company-wide health computation — that's a weekly/monthly cadence
  (`EXECUTIVE_MEETING_GUIDE.md`), not daily, since the underlying
  domain signals don't meaningfully change day to day.

## Reactive, Not Scheduled

Unlike every sibling executive's `DAILY_ROUTINES.md` (which describes a
proactive daily sweep of its own domain's real queues/tables), the
CEO's daily cadence is intentionally reactive: it activates only when a
sibling executive's own routine surfaces something that crosses into
another domain, or when the founder directly asks a cross-domain
question. There is no independent daily "CEO checklist" against
production data, because the CEO has no production data of its own to
check — see `CEO_PROFILE.md`.

## Current Status

As of Phase 8, none of this runs. No `ai/integrations/` layer exists for
any executive, including the CEO, to read live data through. This file
specifies the intended cadence for once that layer and `ai/core/` (the
shared runtime) both exist.
