# ai/prompts

## Purpose
The prompt library for SDOS — system prompts, role definitions, and
reusable prompt fragments that AI executives will be built from.

## Status
Empty. Phase 0 does not define any prompt content.

## What will eventually go here
- Per-executive system prompts (referenced by `ai/executives/`)
- Shared prompt fragments/templates reused across executives
- Versioned prompt history as executives evolve

## What does NOT go here
- Executive logic/config itself (that's `ai/executives/`) — this folder
  holds the text/instructions, not the wiring
